# Cloud Icon Assets

This folder vendors official SVG icon assets for CloudSprocket UI work.

- `aws.svg`, `azure.svg`, and `gcp.svg` are the provider icons currently used in the setup sidebar.
- `aws-rail.svg` is the white AWS wordmark on a transparent background for the dark connection rail.
- `aws-s3.svg`, `aws-ec2.svg`, `aws-lambda.svg`, `aws-dynamodb.svg`, and `aws-systems-manager.svg` are AWS service icons used in the workspace sidebar.
- `azure-resource-groups.svg`, `azure-vm.svg`, `azure-storage.svg`, `azure-app-service.svg`, `azure-log-analytics.svg`, `azure-waf.svg`, `azure-functions.svg`, `azure-key-vault.svg`, `azure-cosmos.svg`, `azure-queues.svg`, and `azure-entra.svg` are Azure service icons used in the workspace sidebar.
- `catalog/aws` contains SVGs from the AWS Architecture Icons package, Q1 2026.
- `catalog/azure` contains SVGs from Microsoft Azure Public Service Icons, V23.
- `catalog/gcp-category` contains SVGs from the current Google Cloud category icon pack.
- `catalog/gcp-legacy` contains SVGs from the Google Cloud legacy icon pack for provider-style and older service glyphs.

Only import individual SVGs that are actively rendered. The catalog is for future use and should not be bulk-imported into the app bundle.
